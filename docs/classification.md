# Classification

This manifest records what is public in this repository and what stays private.

## Public

| Section | Notes |
| --- | --- |
| `characters/` | franchise lore |
| `playlists/` | titles, years, creators, marks, queue state |
| `analysis/` | media structure and craft notes |
| `theories/` | frameworks and general theory |
| `instruments/` | instrument notes |
| `kitchen/recipes/` | recipes |
| `home/housing/` | generic housing runbooks |
| `home/plant/` | generic plant notes |
| `home/consumables/` | reference quantities and prices |
| `reference/tools/` | tool methods and reference prices |
| `reference/sport/` | sport theory |
| `reference/finance/` | generic finance theory only |
| `reference/health/` | generic health-adjacent methods only |
| `reference/career/` | generic career method only |
| `tasks/` | recurring playbooks |
| `src/data/playlists/` | media catalog JSON |
| `src/data/schema/` | catalog schema |

## Private

These stay in `gardusi-gustavo/private` and must not be copied here:

| Section | Reason |
| --- | --- |
| `kitchen/diet/` | age, height, goal weight |
| `practice/` | personal progress |
| `reference/bookmarks/` | personal accounts |
| `reference/infra/` | instance and network details |
| `reference/repo/` | internal repository policy |
| `staging.md` | local media workflow |
| `src/data/bookmarks/` | personal links |
| `src/data/tasks/` | personal task state |
| `theories/thoughts.md` | personal DID and mental-health reflection |

## Rule

A page is public only when it would make sense to a stranger who has seen the
work and knows nothing about the author.
