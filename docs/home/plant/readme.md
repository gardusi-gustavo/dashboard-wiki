# Plant

Growing plants at home.

## Basics

| Topic | Rule |
| --- | --- |
| Light | Match the plant to the window or lamp; more light means more water and food. |
| Water | Water deeply, then let the top layer dry. Drainage is mandatory. |
| Soil | Loose, draining mix; refresh or feed in long cycles. |
| Container | Size to the root ball; repot when roots circle. |
| Feeding | Slow-release or diluted liquid feed; less is safer than more. |
| Pests | Inspect undersides; isolate a new plant before it joins the others. |
| Propagation | Cuttings in water or moist mix; seeds for annuals. |
| Harvest | Herbs and greens: cut and come again; fruit: wait for colour and scent. |

## Rules

- Observe before intervening. Most house-plant deaths are overwatering.
- Keep a saucer or tray under every pot.
- Quarantine new plants for a week.
- This folder is for any plant at home. Cannabis-specific notes are out of scope.
