# 🧳 Onboarding
> **Updated:** 2026-11-02

**What this is:** the first 48 hours in a new stay. It links the records instead
of duplicating the full kit.

## Day 0 — arrive and inventory

- walk every room and note what the unit already has
- confirm stove, fridge, washer, and internet
- check outlet voltage and high-power circuits before buying appliances —
  [electrical.md](electrical.md)
- record the Wi-Fi and host contact in a private note; do not store them here
- check trash day and recycling
- inspect kitchen, bathroom, laundry, closed bedroom, windows, doors, and drains
- map the unit: entries, harbourage, core, and intended gel points
- apply the first interior gel pass — core and baseboards, never window sills,
  door thresholds, or exterior frames
- clean the kitchen and bathroom before unpacking food

## Day 0 — order

- size the first order to the stay length; use the [buy list](../consumables/buy-list.md) for recurring items
- use [tools onboard](../../reference/tools/onboard.md) for the durable kit
- include a frying pan, water filter pitcher + refill, roach gel, gloves, and a
  flashlight unless the unit already has them
- do not duplicate what the unit provides
- order a meal for the first day

## Day 1 — food and routine

- batch cook and portion
- buy perishables only
- set the cleaning cadence from [cleaning.md](cleaning.md)
- confirm the closed bedroom is dry and ventilated

## Week 1 — verify

- trash and recycling actually collected
- no leaks under sinks or washer
- bait points mapped, labeled, unchanged or consumed
- first dead roaches appear by day 3; peak activity in week 1 is expected
- pantry and containers fit the cabinets
- add missing items to [household supplies](../consumables/household.md)

## Check-out

- confirm the date one week ahead
- donate or leave bulky leftovers
- clean the unit and remove bait
- photograph the condition
