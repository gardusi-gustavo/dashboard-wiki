## 🪳 Pest control

The exterior is infinite. The goal is a dead-end interior, not a dead street:
no bait at windows, doors, or drains; concentrate gel in the core where a
colony would establish; inspect and renew every 6–7 weeks. See [pests.md](pests.md).
