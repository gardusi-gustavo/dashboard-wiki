# Consumables

Recurring home purchases: which items to keep in supply and how much.

## Files

| File | Covers |
| --- | --- |
| [buy-list.md](buy-list.md) | monthly purchase catalog — quantities, frequency, reference prices |
| [grocery.md](grocery.md) | fruits, protein, greens, vegetables |
| [pantry.md](pantry.md) | non-perishable food, 3 months max |
| [household.md](household.md) | cleaning and hygiene |

## Rules

- Quantities and item lists live here.
- Reference prices and monthly costs live in [buy-list.md](buy-list.md).
- Actual prices paid, dates, and stores stay in the private ledger.
- One in use, one spare for household and hygiene.
- Pantry is capped at 3 months.
